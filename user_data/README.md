# แก้ไขเนื้อหาเว็บ

ไฟล์ในโฟลเดอร์นี้คือเนื้อหาที่แก้ไขได้เอง ไม่ต้องรู้โค้ด แก้ในไฟล์ไหนก็มีผลแค่ส่วนนั้น
เปิดด้วย text editor ธรรมดา (Notepad, TextEdit, VS Code) แก้ข้อความในเครื่องหมาย `"..."`
แล้วเซฟ — **ห้ามลบเครื่องหมาย `,` `{ }` `[ ]` `"` ที่ล้อมข้อความอยู่** ไม่งั้นเว็บจะพัง

ถ้าไม่มั่นใจ ลองเช็คไฟล์ที่ https://jsonlint.com ก่อนอัปโหลดได้

## รหัสผ่าน (mission.json)
วันที่เจอกันครั้งแรก ใช้ปลดล็อกหน้า 2 ของเว็บ (ผู้รับต้องกรอกวันที่นี้เป็นรหัส 6 หลัก)
```
day: วันที่ (1-31)
month: เดือน (1-12)
year: ปี พ.ศ. (เช่น 2569)
```

## แชท (chat.json)
บทสนทนาในหน้า 3 เล่นเรียงจากบนลงล่างตามลำดับในไฟล์
- `{ "from": "me", "text": "..." }` — ข้อความที่พิมพ์มาเอง
- `{ "from": "her", "options": ["...", "...", "..."] }` — ตาที่อีกฝ่ายเลือกตอบ (แนะนำ 3 ตัวเลือก) กดอันไหนก็ไปต่อเหมือนกัน ไม่ได้เปลี่ยนเนื้อเรื่อง
- **บรรทัดสุดท้ายของไฟล์ต้องเป็น `"her"` เสมอ** เพราะการกดตอบครั้งสุดท้ายคือตัวเปลี่ยนไปหน้าถัดไป

## คำถามความรัก (quiz.json)
คำถามหน้า 6 แต่ละข้อมี `question`, `options` (ตัวเลือก), `correctIndex` (index ของคำตอบที่ถูก นับจาก 0)
ตอบข้อไหนก็ไปต่อได้เหมือนกัน (ไม่มีทางตอบผิดจนติด) — `correctIndex` เก็บไว้เฉยๆ เผื่อใช้ในอนาคต

## รูปถ่าย (camera.json)
รูปที่ออกมาจากกล้องในหน้า 5 ใส่ทีละรูปแบบนี้:
```json
{ "src": "assets/photos/1.jpg", "caption": "ทริปแรกของเรา" }
```
เอารูปจริงไปวางไว้ในโฟลเดอร์ `assets/photos/` ก่อน แล้วใส่ชื่อไฟล์ตรงนี้ (caption จะใส่หรือเว้นว่างก็ได้)
จำนวนรูปกี่ใบก็ได้ — ใส่กี่รูปก็ออกจากกล้องกี่ครั้ง

## ไทม์ไลน์ (timeline.json)
เหตุการณ์สำคัญในหน้า 7 เรียงจากเก่าไปใหม่ แต่ละอันมี `date`, `title`, `note` (จะเว้นว่างก็ได้)
**ลำดับที่ N ในไฟล์นี้จะจับคู่กับรูปที่ N ใน camera.json** อยากให้ตรงกันต้องเรียงให้สอดคล้องกัน

## คำอวยพร (wishes.json)
ข้อความในนกกระดาษแต่ละตัวที่หน้าสุดท้าย (หน้า 8) ใส่กี่ข้อความก็ได้ = มีนกกระดาษเท่านั้นตัว

## ข้อมูลทั่วไป (basics.json)
- `names` — ชื่อคู่รัก (ยังไม่ได้ใช้แสดงผลตอนนี้ เผื่ออนาคต)
- `relationshipLabel` — ข้อความใต้หัวข้อหน้ากล้อง เช่น "3 ปี 1 เดือนของเรา"
- `song` — เพลงพื้นหลัง วาง link YouTube ที่ `youtubeUrl` ได้เลย (`youtube.com/watch?v=...` หรือ `youtu.be/...`)
  - `startSeconds` — เริ่มเล่นวินาทีที่เท่าไหร่
  - `volume` — ความดัง 0-100

## ทำเว็บหลายภาษา (?lang=xx)
ถ้าอยากได้เวอร์ชันภาษาอื่นด้วย (เช่นภาษาอังกฤษ) สร้างโฟลเดอร์ย่อยตามรหัสภาษา
เช่น `user_data/en/` แล้วก็อบไฟล์ json อันไหนที่อยากแปลไปวางไว้ในนั้น ไม่ต้องก็อบครบทุกไฟล์
— ไฟล์ไหนไม่มีในโฟลเดอร์ภาษานั้น เว็บจะใช้ไฟล์ไทยเดิม (`user_data/xxx.json`) แทนโดยอัตโนมัติ

เปิดเว็บด้วย `?lang=en` ต่อท้าย URL (เช่น `https://yourdomain.com/?lang=en`) เพื่อดูเวอร์ชันนั้น
ไม่ใส่ `?lang=` เลย = ภาษาไทย (ค่าเริ่มต้น)

---
ไฟล์เหล่านี้โหลดผ่าน `fetch()` ตอนเปิดเว็บ ต้องรันผ่านเว็บเซิร์ฟเวอร์ (เช่น deploy จริงบน Cloudflare Pages)
เปิดไฟล์ index.html ตรงๆ จากเครื่อง (`file://...`) จะโหลดไม่ขึ้นเพราะเบราว์เซอร์บล็อก — ถ้าจะทดสอบในเครื่องก่อน ให้รันเซิร์ฟเวอร์เล็กๆ เช่น `python3 -m http.server` แล้วเปิดผ่าน `http://localhost:...`
